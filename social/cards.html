✓ cargo‑vouch
It proves your Rust can’t panic. Not tests. Proofs.
Point it at a function. It checks every input in bounds and reports BUG, UNGUARDED, or VERIFIED, with the value that triggers the bug.
cargo vouch
$ cargo vouch find_max.rs
🔴 BUG  find_max  called `Option::unwrap()` on a `None` value       reachable with input: 0 (usize → empty vector)

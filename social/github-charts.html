github readme · the honest limitation

Verification time by function shape

Instant on arithmetic. Off the chart on loops.

This is the whole story of when to use it. Straight-line arithmetic and indexing verify in about a second. Anything with a data-dependent loop runs bounded model checking out of depth and comes back INCONCLUSIVE — never a false pass, but no answer.
